# 🥷 Digital SAT Reading & Writing Suite — Ninja Practice Tests (270 Questions)

An authentic, modern interactive web application containing all **270 Digital SAT Reading & Writing questions** across **5 complete official practice test forms** (Tests 1, 2, 3, 4, and 5), featuring a PsychSAT-inspired aesthetic with high-performance 2D cyber background, Miyabi's focus ears, Cissia's lucky tail, the authentic College Board 2-module timed exam experience with official 200–800 scaled scoring, and a dedicated **Untimed Practice Mode**.

🌐 **Live Demo (GitHub Pages)**: [https://elshod-gosling.github.io/ninja-sat-bluebook/](https://elshod-gosling.github.io/ninja-sat-bluebook/)

---

## 🎯 Features

### 🌌 PsychSAT Design System & Custom Artwork
- **Obsidian Dark / Clean Light Mode**: Deep dark palette (#08090e) with electric violet and lilac neon accents (#8b5cf6, #c4b5fd), and a high-performance Solar Amber light theme.
- **Cyber 2D High-Performance Animated Background**: Smooth canvas particle network and ambient perspective grid.
- **Miyabi's Ears**: Top navbar badge emblem and footer decorative element.
- **Cissia's Tail**: Playful animated mascot swaying along the 270-question Master Suite card.
- **Score Ruler**: Dynamic target score ruler (600 → 680 → 740 → 800 MAX).
- **Interactive Easter Eggs**: Clickable mascot elements and target score pills with custom focus toasts.

### ⏱️ Official SAT 2-Module Timed Exam & Untimed Practice Mode
- **Authentic 2-Module Structure**:
  - **Module 1**: 27 Questions, 32-minute countdown timer.
  - **Inter-Module Break**: Official SAT transition dialog summarizing answered/unanswered/flagged questions before locking Module 1.
  - **Module 2**: 27 Questions, 32-minute countdown timer.
- **♾️ Dedicated Untimed Mode**:
  - Practice at your own pace without ticking timer pressure.
  - Seamless toggle on the home hub or test header with 1 click or keypress (U).
- **Official 200–800 Scaled Scoring**:
  - Non-adaptive equating curve mapping raw correct score directly to the College Board 200–800 scale (e.g., 54 = 800, 50 = 750, 40 = 640, 27 = 510).
  - Domain mastery breakdown and percentile bands in the comprehensive score report.

### 📚 Complete Content & Bluebook Testing Tools
- **Full Ninja Master Suite**: Practice all 270 questions sequentially across all 5 test forms.
- **Individual Practice Tests**: Tests 1, 2, 3, 4, and 5 available as complete 54-question 2-module exams or individual modules.
- **Triple Modes**:
  - **⚡ Practice Mode**: Instant check answer with detailed rationales and feedback.
  - **⏱️ Official Exam Mode**: Authentic timed 32m + 32m exam delivery.
  - **♾️ Untimed Mode**: Self-paced testing with zero rush.
- **Highlighter Toolbar**: Yellow, Pink, and Cyan text highlighting with an instant removal tool and floating popover.
- **Answer Elimination**: Strikethrough (ABC) tool to rule out incorrect choices.
- **Question Navigator**: 27 / 54 / 270 question palette modal with status filtering (All, Unanswered, Flagged, Incorrect).
- **Interactive Blank Preview**: Selecting an answer dynamically previews the chosen word inside the passage's blank.
- **Authentic Scan Modal**: Click [ 📄 Scan ] anytime to inspect the original PDF source page.
- **Keyboard Shortcuts**:
  - ← / →: Previous / Next question
  - A, B, C, D or 1, 2, 3, 4: Select answer choice
  - Enter: Check Answer (in Practice Mode)
  - M: Toggle Mark for Review flag
  - U: Toggle Untimed Mode
